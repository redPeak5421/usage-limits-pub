# Usage Limits

iOS 用量看板。在 App 里登录各家 AI 官方站点，把订阅和预充值的**用量、额度、重置时间**收在一处；桌面小组件和 Apple Watch 也能看。

无服务器、无统计 SDK。凭据只留在本机。

## 隐私

- 登录在各家**官方页面**内完成。Cookie 和站内 token 只存在本机系统存储里，不上传、不经过任何自有服务器。
- 自定义用量的访问令牌同样只存在本机，不进用量快照，也不进手表。
- App 只向各家官方域名发请求；自定义接口走本机 HTTPS GET。
- 本地保存的用量只有数字和时间，不含 token / cookie。
- 「退出登录」会清除该站点在本机的全部数据。

## 支持的服务

当前开放 11 家：Claude、ChatGPT（Codex）、Grok、Cursor、DeepSeek、智谱、Kimi、MiniMax 国内、即梦、OpenCode、Gemini。

其余 14 家接入暂时隐藏，代码和已保存账号仍保留，待验证后恢复。核验依据见 [供应商接入状态](providers/availability.md)。

也可以添加**自定义用量源**：填写任意 HTTPS JSON 接口，或选用内置模板。

## 功能

- **用量看板**：卡片折叠看主用量，展开看全部计量条；未使用的指标默认收起。
- **多账号**：同一服务可加多个账号，登录态互相隔离；首页可拖动排序。
- **登录**：内置浏览器打开官方站点，支持邮箱验证码以及站点提供的社交登录。
- **刷新**：下拉刷新、回前台自动刷新、可调间隔、后台刷新。
- **显示**：已用 / 剩余、重置倒计时 / 绝对时刻、每张卡片的计量顺序都可改。
- **套餐标价**：展开卡片可见各家套餐的月付 / 年付参考价。
- **提醒**：用量阈值通知，可按服务单独设置。
- **小组件**：2×2 单账号、2×4 单账号多计量、2×4 / 4×4 总览。
- **Apple Watch**：环形用量，可切换账号。
- **分享**：生成用量分享图。
- **外观**：首页平铺 / 轮盘 / 螺旋；中 / 英 / 日 / 法 / 俄；深色 / 浅色 / 跟随系统。
- **侧边键**：用 iPhone 操作按钮打开侧边菜单。
- **演示模式**：未登录也可先看界面。

## 使用

1. 首页点卡片上的「登录」，在官方页面完成登录。内嵌浏览器里 Google 登录可能受限，优先用邮箱验证码。登录成功后会拉取用量。
2. 卡片默认折叠，抬头是商标和套餐；点开后显示周期、参考价和全部用量条。
3. 下拉刷新全部账号。回到 App 后，超过间隔的已登录账号会自动刷新。
4. 设置 → 服务商：可关闭某家（首页和小部件不再出现，登录态保留）、管理多账号、添加自定义源。
5. 桌面长按空白 →「+」→ 搜索「Usage Limits」添加小组件。2×2 可在编辑里切换账号。
6. 想先看效果：设置 → 演示模式。

## 说明

- 用量来自各家官网当前提供的数据。站点改接口后，可能暂时只有套餐、没有数字额度。
- ChatGPT 网页端没有稳定的普通对话额度数字，能看到的是套餐信息和 Codex 用量窗口（如有）。
- 小组件显示的是 App 最近一次刷新的缓存；打开 App 或后台刷新后会更新。
